API ENDPOINTS TO USE
====================

Create Topology:
  POST /api/topologies

Start Emulation:
  POST /api/emulation/start
  {topology_id, options}

Add Device Dynamically:
  POST /api/topologies/{topology_id}/apply
  {changes: {add_devices: [...]}}

List Devices:
  GET /api/emulation/devices?device_type=container

Stop Emulation:
  POST /api/emulation/stop/{emulation_id}

Get Node Properties:
  GET /api/topologies/{topology_id}/nodes/{node_id}
